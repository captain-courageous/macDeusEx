### What's New in v0.2.0

- **Deus Ex: Revision Mod Support**
  - Full engine integration for Deus Ex: Revision, including `DXOgg` Ogg Vorbis audio playback, `ConSys` native conversation/platform hooks, Revision/HDTP/NewVision asset resolution, and Revision menu settings integration.
  - Install Revision during setup or add/upgrade later with `--revision <path>` / `--with-revision`, or let `quick-install.sh` download and extract Revision's official Windows installer/patch (`.zip` / `.wim` via `7zz`, or GOG `.exe` via `innoextract`).
- **Performance & Responsiveness**
  - Faster Metal rendering, BSP clipping, and RTTI/VM hot paths (~5.6% lower process CPU time at 4K 120 Hz on UNATCO Island).
  - Native Cocoa fullscreen handling and reduced idle CPU usage.
- **Audio & macOS App Polish**
  - Active CoreAudio/OpenAL sample rate (e.g., `48000 Hz`) is reflected accurately in `OutputRate` and Settings -> Sound, with restored music/sound volume scaling.
  - Preserves the `Deus Ex.app` custom Dock icon across launches and fixes BGRA PE icon color channel swapping.
- **Seamless In-Place Updates**
  - Re-running `quick-install.sh` on an existing `Deus Ex.app` updates the engine in-place using APFS copy-on-write clones while keeping saves, `.ini` configs, app icon, and any installed Revision mod.
