### What's New in v0.2.1

- **Gameplay & Keybinding Fixes**
  - Fixed `AttachTag` base attachment so movers and breakable targets (such as the shooting range glass target in Training `#1`) attach and move properly with their parent mover.
  - Fixed `SET`/`GET` console command matching for package-qualified input classes (`Engine.Input` / `Extension.InputExt`), fixing key remapping (including middle mouse button `#3`) across both Vanilla and Revision.
- **UI, Controls & Widescreen Fixes**
  - Scaled menu cursor speed with the in-game Mouse Sensitivity setting and added sub-pixel trackpad/mouse delta accumulation (`#4`).
  - Fixed **Restore Defaults** across **Controls**, **Keyboard/Mouse**, and **Game Options** in both Vanilla and Revision.
  - Extended the pause backdrop dim overlay across the full widescreen display and fixed full-root viewport cutouts so cutscenes and dialogues render without side black bars.
- **Audio**
  - Follow macOS System Sound output device changes in real time via CoreAudio notifications and `alcReopenDeviceSOFT`.
- **Installer (`quick-install.sh`)**
  - Added offline GOG `.exe` installer extraction via `innoextract` (including GOTY + bundled Revision installers, `#2`).
  - Detected Steam console `download_depot 6910 6911` installs (including external Steam library folders) and updated macOS Steam guidance (`PR #5` by `@lukad`).
